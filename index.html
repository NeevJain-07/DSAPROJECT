Doubly Linked List (O(1) Next/Prev)

Each node holds prev and next pointers. Skipping forward/backward takes $O(1)$ operations with zero shifting.

FIFO Play Queue (First-In, First-Out)

Songs added with "+ Queue" play first before the playlist continues. Songs enter at rear and leave at front.

LIFO Playback History Stack

Every finished or skipped song gets pushed onto the top of the stack. Clicking "Previous" pops the top of the stack.

Binary Search Tree (O(log N) Lookup)

Songs in the library catalog are sorted alphabetically by title. In-order traversal visits tracks in sorted order.

c_src/music_player.h — Core Data Structures 
/* 1. Doubly Linked List Node */
typedef struct SongNode {
    Song song;
    struct SongNode *prev; /* O(1) Prev pointer */
    struct SongNode *next; /* O(1) Next pointer */
} SongNode;

/* 2. FIFO Play Queue (Up Next) */
typedef struct QueueNode {
    Song song;
    struct QueueNode *next;
} QueueNode;

typedef struct {
    QueueNode *front; /* Dequeue target */
    QueueNode *rear;  /* Enqueue target */
    int count;
} SongQueue;

/* 3. LIFO History Stack */
typedef struct StackNode {
    Song song;
    struct StackNode *next;
} StackNode;

typedef struct {
    StackNode *top; /* Most recently played */
    int count;
} HistoryStack;

/* 4. Binary Search Tree (Library Index) */
typedef struct BSTNode {
    Song song;
    struct BSTNode *left;
    struct BSTNode *right;
} BSTNode;

🎓 College Presentation & Viva Highlights

TuneStream is the textbook real-world application of linear and hierarchical Data Structures in C:

  1. Doubly Linked List (Playlist): Bi-directional node pointers (prev & next) enable $O(1)$ Next and Previous track navigation and $O(1)$ track insertions/deletions.
  2. FIFO Queue (Up Next): User-queued tracks play first in First-In, First-Out order.
  3. LIFO Stack (Recently Played): Stores finished tracks. Going back pops the top of the stack.
  4. Binary Search Tree (Library Search): Organizes the full catalog alphabetically for rapid $O(\log N)$ search queries.
