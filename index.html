Left-Child Right-Sibling Representation

Every directory node holds a firstChild pointer to its first sub-item, and items at the same level are connected via nextSibling pointers.

LIFO Stack Structure

Used to resolve current working directory (pwd) and backtrack backwards (cd ..) by pushing and popping folder pointers.

FIFO Queue Structure

Maintains an operation log (mkdir, touch, rm). Enqueued at the rear, dequeued from the front when full.

c_src/vfs.h — Core Data Structures 
/* N-ary Tree Node (LCRS Representation) */
typedef struct FSNode {
    char name[64];
    NodeType type;            /* NODE_DIR or NODE_FILE */
    char *content;            /* File content string */
    size_t size;              /* File size in bytes */
    time_t created_at;

    struct FSNode *parent;     /* Parent directory */
    struct FSNode *firstChild; /* First subfolder/file */
    struct FSNode *nextSibling;/* Next item at same depth */
} FSNode;

/* Navigation Stack for 'pwd' and 'cd ..' */
typedef struct StackNode {
    FSNode *node;
    struct StackNode *next;
} StackNode;

typedef struct {
    StackNode *top;
    int size;
} PathStack;

/* Activity Queue (FIFO) */
typedef struct QueueNode {
    char action[128];
    time_t timestamp;
    struct QueueNode *next;
} QueueNode;

typedef struct {
    QueueNode *front;
    QueueNode *rear;
    int count;
} ActivityQueue;

Project Overview & GitHub Pages Deployment Guide

🎓 College Viva & Presentation Highlights

This project implements an Operating System Virtual File System (VFS) in C using 3 core Data Structures:

  1. N-ary Tree (General Tree): Implemented using textbook Left-Child Right-Sibling (LCRS) representation. Each directory points to its first child and next sibling, eliminating memory waste from fixed-sized arrays.
  2. Linked List Stack: Resolves current working path (pwd) and backtracks directory levels (cd ..) via LIFO order.
  3. FIFO Queue: Maintains chronological history of system operations with bounded capacity.
